# Changelog

## v0.2.6

- Смена кодовой фразы без потери отметок: записи перешифровываются и переносятся на новый путь в облаке, старая база удаляется
- Открытые вкладки author.today синхронизируются сразу после сохранения или смены фразы
- Полное удаление всех данных: облачные отметки, отметки в браузере, кодовая фраза
- Список устройств в параметрах: переименование, удаление чужого устройства с тихим локальным сбросом при следующей синхронизации
- Имена и платформы устройств хранятся в облаке зашифрованными кодовой фразой
- Строка свежести «Данные на HH:MM» в блоке статистики
- Три счётчика статистики в ряд, кнопки настроек отцентрованы по ширине карточки
- README переписан

## v0.2.5

- Тумблер «Скрыть отмечённые» в шапке списков и таблиц
- В плиточном виде отмечённые карточки тоже скрываются (без кнопки тумблера)
- A/B-замер влияния расширения на скорость страницы (npm run perf), автотесты на каждый push (GitHub Actions), скрипт релиза (npm run release)

## v0.2.4

- Экспорт и импорт отметок в JSON через параметры расширения

## v0.2.3

- Иконки расширения 16/32/48/128; клик по иконке в тулбаре открывает параметры

## v0.2.2

- Счётчики статистики (прочитано / брошено / всего) в параметрах

## v0.2.1

- Автоповтор синхронизации при ошибках сети с нарастающей задержкой
- Удаление томбстоунов старше 90 дней

## v0.2.0

- Облачная синхронизация между устройствами через Firebase Realtime Database по кодовой фразе, шифрование AES-GCM
- Показ и копирование кодовой фразы в параметрах
- Установка через .crx, лицензия 0BSD

## v0.1.0

- Первая версия: отметки ✅/❌ рядом с названиями книг на страницах author.today, хранение локально

Синхронизация не настроена

Не найден конфиг Firebase. Заполните файл .env в папке проекта (значения из Firebase-консоли → Project settings → SDK setup) и выполните в терминале npm run config, затем перезагрузите расширение.

Без конфига расширение работает локально: отметки сохраняются в браузере, но не синхронизируются.

Кодовая фраза

Фраза из ~15 слов — это ваш «пароль» и ключ к отметкам. Введите её на другом устройстве, и все записи восстановятся. Запишите фразу в безопасное место: без неё доступ невосстановим.

Синхронизация

Пользователь (userId)
—
Последняя синхронизация
никогда
Статус
—

«Выйти» удаляет фразу только с этого устройства — облачные отметки останутся, доступ к ним даст повторный ввод фразы.

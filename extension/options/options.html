Author.Today — отметки книг

Синхронизация не настроена

Не найден конфиг Firebase. Заполните файл .env в папке проекта (значения из Firebase-консоли → Project settings → SDK setup) и выполните в терминале npm run config, затем перезагрузите расширение.

Без конфига расширение работает локально: отметки сохраняются в браузере, но не синхронизируются.

Кодовая фраза

Фраза из ~15 слов — это ваш «пароль» и ключ к отметкам. Введите её на другом устройстве, и все записи восстановятся. Запишите фразу в безопасное место: без неё доступ невосстановим.

Фраза — единственный доступ к облачным отметкам: без неё записи восстановить нельзя. Не передавайте её третьим лицам.

Смена кодовой фразы

Все отметки будут перешифрованы новой фразой и перенесены на новый путь в облаке; старая база удаляется — доступ по старой фразе пропадает полностью. Отметки не теряются.
Сразу после смены введите новую фразу на всех остальных устройствах, иначе они продолжат работать со старой фразой.

Фраза заменена. Введите её на остальных устройствах.

«Выйти» удаляет фразу только с этого устройства — облачные отметки останутся, доступ к ним даст повторный ввод фразы.

Бэкап

Экспорт выгружает отметки этого браузера в файл (данные — на момент последней синхронизации с author.today). Импорт объединяет файл с текущими отметками: более новые записи не затираются. Фраза и конфиг для бэкапа не нужны.

# Author.Today — отметки книг

Chrome-расширение (Manifest V3): кнопки **[+]** и **[−]** с индикатором
**✅ / ❌ / пусто** рядом с названием книги в списках и таблицах поиска и
каталога [author.today](https://author.today/), а также в заголовке самой
страницы книги. Отметки хранятся в `localStorage` браузера и **синхронизируются
между устройствами через Firebase** по кодовой фразе (v0.2.0).

Спецификация проекта (для разработчиков/агентов): **[AGENTS.md](AGENTS.md)**.

## Установка

**Вариант А — готовый архив (рекомендуется):**

1. Скачайте `author-today-readed-X.Y.Z.zip` из
   [Releases](https://github.com/Rocaccel/author-today-readed/releases)
   и распакуйте в любую папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (правый верхний угол).
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную
   папку (в ней сразу лежит `manifest.json`).

**Вариант Б — из исходников:**

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (правый верхний угол).
3. Нажмите **Загрузить распакованное расширение** и выберите папку
   `author-today-readed/extension`.
4. Откройте `https://author.today/work/genre/fantasy` — у каждого заголовка
   книги в списке появится панель отметок.

## Где работает

| Страница | Вид «список (строки)» | Вид «таблица» | Вид «плитка» |
|---|---|---|---|
| `/work/*` (каталог, жанры, скидки…) | ✅ | ✅ | — |
| `/search?category=works` | ✅ | ✅ | — |
| `/work/NNN` (страница книги) | панель внутри `h1` заголовка | — | — |
| остальные страницы, главная, плитка | — | — | — |

На странице книги панель стоит в одну строку сразу после текста названия;
отметка **общая** со списком (тот же ключ `localStorage`).

## Синхронизация между устройствами (v0.2.0)

Отметки синхронизируются через **Firebase Realtime Database**. Входа по
логину-паролю нет: единственный доступ — **кодовая фраза** (~15 слов). Из неё
выводится идентификатор пользователя и ключ шифрования — в облаке лежат только
шифротексты, без фразы данные нечитаемы.

### Настройка (один раз)

1. В [Firebase Console](https://console.firebase.google.com/) →
   **Build → Realtime Database → Create database** (если БД ещё нет; у вас
   она уже создана — `databaseURL` вида
   `https://<проект>-default-rtdb.<регион>.firebasedatabase.app`).
2. Настройте правила базы: **Realtime Database → вкладка Rules** —
   данные зашифрованы, поэтому правила открыты:

   ```json
   {
     "rules": {
       "users": {
         "$userId": {
           "marks": {
             ".read": true,
             ".write": true
           }
         }
       }
     }
   }
   ```

   **Publish** (предупреждение консоли об открытом доступе — ожидаемо,
   контент шифрованный).
3. В папке проекта заполните файл **`.env`** (он в `.gitignore`, на GitHub не
   попадает): минимум `FIREBASE_DATABASE_URL`. Можно вставить и JS-блок
   `const firebaseConfig = {...}` из консоли целиком — скрипт разберёт.
4. Выполните в терминале:

   ```
   npm run config
   ```

   Это создаст `extension/background/config.js` (тоже в `.gitignore`).
5. Перезагрузите расширение в `chrome://extensions`.

Без конфига расширение работает локально — синхронизация просто выключена.

### Вход по кодовой фразе

1. `chrome://extensions` → расширение «Author.Today — отметки книг» →
   **Настройки** (options-страница).
2. **«Создать фразу»** — расширение сгенерирует 15 слов; **запишите их в
   безопасное место** (подтвердите чекбоксом) → «Сохранить и войти».
   Или введите свою фразу (12–30 слов).
3. На другом устройстве: тот же конфиг Firebase → в той же options-странице
   ввести **ту же фразу** → открыть author.today — отметки подтянутся.

Потеря фразы = потеря доступа к облачным отметкам. Фраза хранится только
на устройстве (в `chrome.storage.local` расширения), сайт её не видит.

## Как отметить книгу

- **`+`** — поставить `✅`; повторное нажатие снять отметку.
- **`−`** — поставить `❌`; повторное нажатие снять отметку.
- Нажатие при чужой отметке **заменяет** её своей.
- Отметка общая для всех страниц: перезагрузка и другие вкладки её видят
  (ключ localStorage: `atr.v1.marks`).

## Структура

```
AGENTS.md              полная спецификация проекта (для разработчиков и агентов)
.env                   конфиг Firebase (GITIGNORE, заполняет пользователь)
package.json           тесты + npm run config
scripts/apply-config.js  .env → extension/background/config.js
tests/                 автотесты jsdom
extension/             ← грузится в Chrome как распакованное расширение
  manifest.json           MV3 (permissions: storage; options_ui; host: rtdb)
  content/storage.js      хранение в localStorage, схема v2 + миграция
  content/sync.js         синхронизация с Firebase (content ↔ background)
  content/ui.js           панель [+] [индикатор] [−]
  content/dom.js          вставка в DOM + MutationObserver/pjax
  content/main.js         точка входа
  content/styles.css      стили (light/dark)
  shared/phrase.js        кодовая фраза, userId, PBKDF2/AES-GCM
  options/                страница настроек (фраза, статус, синхронизация)
  background/service-worker.js  роутер сообщений + хранилище фразы
  background/firebase.js  Realtime Database REST-клиент (GET/PATCH/sync)
  background/config.js    ГЕНЕРИРУЕТСЯ из .env (GITIGNORE)
```

Сборка не требуется: чистый JavaScript, файлы подключаются как есть.

## Тесты

Автотесты в jsdom (без браузера) — из корня проекта:

```
npm install   # один раз, ставит jsdom (только для тестов)
npm test
```

Проверяют: инжект панелей в список/таблицу, исключение плитки, семантику
кнопок, схему хранилища v2 и миграцию с v1, LWW-слияние с томбстоунами,
панель на странице книги, генерацию фразы, детерминированный userId,
шифрование AES-GCM (чужой ключ падает), протокол синхронизации
content ↔ background.

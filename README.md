# Author.Today — отметки книг

Chrome-расширение (Manifest V3): кнопки **[+]** и **[−]** с индикатором
**✅ / ❌ / пусто** рядом с названием книги в списках и таблицах поиска и
каталога [author.today](https://author.today/), а также в заголовке самой
страницы книги. Отметки хранятся только локально в `localStorage` браузера.

Спецификация проекта (для разработчиков/агентов): **[AGENTS.md](AGENTS.md)**.

## Установка

**Вариант А — готовый архив (рекомендуется):**

1. Скачайте `author-today-readed-X.Y.Z.zip` из
   [Releases](https://github.com/Rocaccel/author-today-readed/releases)
   и распакуйте в любую папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (правый верхний угол).
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную
   папку (в ней сразу лежит `manifest.json`).

**Вариант Б — из исходников:**

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (правый верхний угол).
3. Нажмите **Загрузить распакованное расширение** и выберите папку
   `author-today-readed/extension`.
4. Откройте `https://author.today/work/genre/fantasy` — у каждого заголовка
   книги в списке появится панель отметок.

## Где работает

| Страница | Вид «список (строки)» | Вид «таблица» | Вид «плитка» |
|---|---|---|---|
| `/work/*` (каталог, жанры, скидки…) | ✅ | ✅ | — |
| `/search?category=works` | ✅ | ✅ | — |
| `/work/NNN` (страница книги) | панель внутри `h1` заголовка | — | — |
| остальные страницы, главная, плитка | — | — | — |

На странице книги панель стоит в одну строку сразу после текста названия;
отметка **общая** со списком (тот же ключ `localStorage`).

## Как отметить книгу

- **`+`** — поставить `✅`; повторное нажатие снять отметку.
- **`−`** — поставить `❌`; повторное нажатие снять отметку.
- Нажатие при чужой отметке **заменяет** её своей.
- Отметка общая для всех страниц: перезагрузка и другие вкладки её видят
  (ключ localStorage: `atr.v1.marks`).

## Структура

```
AGENTS.md      полная спецификация проекта (для разработчиков и агентов)
package.json   только для тестов (npm test)
tests/         автотесты jsdom
extension/     ← грузится в Chrome как распакованное расширение
  manifest.json           MV3-манифест (без permissions)
  content/storage.js      хранение в localStorage
  content/ui.js           панель [+] [индикатор] [−]
  content/dom.js          вставка в DOM + MutationObserver/pjax
  content/main.js         точка входа
  content/styles.css      стили (light/dark)
  background/service-worker.js  ES-модуль, инициализация
  background/firebase.js  заглушка модуля Firebase (без подключения)
```

Сборка не требуется: чистый JavaScript, файлы подключаются как есть.

## Тесты

Автотесты в jsdom (без браузера) — из корня проекта:

```
npm install   # один раз, ставит jsdom (только для тестов)
npm test
```

Проверяют: инжект панелей в список/таблицу, исключение плитки, семантику
кнопок, хранилище `atr.v1.marks`, перерисовку после pjax, панель на
странице книги.
